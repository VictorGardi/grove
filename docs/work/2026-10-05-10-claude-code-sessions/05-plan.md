## Slice 3 — Claude live status

Context: after slice 2, core keeps one `SourceState` per registered `AgentSource`; a session whose
kind has no source gets no status. Claude has no source yet: `sessionCreate` launches it through
slice 1's `claudeSpoolDir` bridge (`claudeArgv` + `mkdirSync`). This slice adds `SpoolClaude`
(design "Hook → event mapping", two-way decisions 6–8), registers it, and removes the bridge. Write
paths (`wrote`), `lastWrites`, resume ids and `forget` stay for slices 4–5: `lastWrites` returns
`[]`, `forget` does nothing, `argv(id, 'resume')` passes no resume id.

Shapes used below. A spool record is `{ t: string; e: unknown }` (`t` is UTC to the second, e.g.
`2026-10-07T06:35:03Z`). In a hook payload `e`: `hook_event_name`, `tool_name`, `tool_use_id`,
`agent_id` (subagents only; `scope` = `agent_id` if it is a string, else `'main'`). Event times
are `t` with `Z` replaced by `.000Z` (seen marks are ISO with milliseconds; string comparison
needs the same form).
