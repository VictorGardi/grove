## Working in this repo

- Domain glossary: `GLOSSARY.md`. Use its terms.
- Run `npm test` and `npm run typecheck` before committing.
- ADRs go in `docs/adr/` (see the existing ones first); write one only for a decision that needs it.

## Agent skills

### Issue tracker

Issues and specs are local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage roles, recorded as a `Status:` line in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
