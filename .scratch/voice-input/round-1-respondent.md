## Conflicts / gaps
- D4 recommendation text misdescribes the diff panel rule (see above).
- No ADR conflicts. Brief tension: "works offline" and "no network" vs D2 download.
- Code cites nonexistent ADR 0023/0055 (paste rule); not blocking.

## Surprising and hard to reverse (beyond D1-D7)
1. Voice is a new key-action kind (hold with release), which changes keys.json/binding rules (space allowed, release path, "bound to two actions" still invalid). Hard to undo once users have keys.json entries.
2. Build now needs cmake and Xcode CLT (whisper.cpp) and adds a native audio dependency; Intel and Metal behaviour unverified.
3. Mic permission is tied to bundle identity dev.grove.app and signing; changing identifier or signing later resets grants.
4. Voice is a host feature, not a Module (glossary), and needs new glossary terms: agent tab, push-to-talk key, listening indicator, voice input.
5. Language: Whisper multilingual vs .en model choice fixes the language story (brief says default to Mac language); using .en would contradict that.
